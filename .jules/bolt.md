## 2025-02-18 - Optimized Map Clustering & Rendering
**Learning:** Leaflet maps with dynamic markers (especially clusters) are performance bottlenecks because `react-leaflet` updates DOM elements whenever props (icon, eventHandlers) change, even if functionally identical. Additionally, calculating cluster properties (like "top location") in the render loop is O(N) where N is number of points, causing jank on map moves.
**Action:** Use `Supercluster`'s `map` and `reduce` options to pre-calculate expensive properties (e.g. `topLocation`) during the clustering phase (background/efficient). Wrap `Marker` in a `React.memo` component (`MemoizedMarker`) and use `useMemo` for `icon` and `eventHandlers` to ensure referential stability and prevent DOM thrashing. Memoize callbacks passed to markers.
